# myHealth — UI Wireframes

**Version:** 1.0  
**Date:** 2026-04-19  

Legend:
```
[ Button ]   = clickable button
[ Input__ ]  = text input field
[v]          = dropdown / select
(●)          = selected radio / active state
( )          = unselected radio
[x]          = close / delete
[+]          = add / new
[≡]          = menu / list
[↑]          = upload
[↓]          = download / export
[🔍]         = search
[◀] [▶]     = navigation arrows
```
